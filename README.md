# icpc

算法竞赛练习记录（C++ / Python）。

## 整理规则

1. 一级目录只按来源分：`atcoder/`、`aoj/`、`other/`（来源未记录）。
2. AtCoder：`atcoder/<比赛>/<字母>.<ext>`，字母取题目链接 task id 的末尾（如 `arc088_b` → `arc088/b.cpp`；老 ARC 的 task id 字母与页面显示的字母不同）。
3. AOJ：`aoj/<题号>.<ext>`。
4. 同一题多个版本：无后缀的是最终版，其他版本加后缀（`c_v1.py`、`d_refactor.cpp`）。
5. 专题、原文件名里的描述放在本 README 的“标签与备注”里，不再单独建专题目录。
6. `other/` 里的文件保持原名；查到来源后按以上规则移出。
